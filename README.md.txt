# Call Center Report Dashboard - 2025 (Excel)

## Project Overview

This project presents an interactive **Call Center Performance Dashboard** built using Microsoft Excel.
The dashboard analyzes call center operations such as total calls, revenue generated, call duration, customer satisfaction, and representative performance.

The goal of this project is to demonstrate how Excel can be used to transform raw call center data into meaningful insights using **pivot tables, charts, and slicers**.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Visualization

## Key Performance Indicators (KPIs)

* Total Calls: 1,000
* Total Revenue Generated: $96,623
* Total Call Duration: 89,850 seconds
* Average Customer Rating: 3.9
* Happy Calls: 307

## Dashboard Features

The dashboard includes several visualizations to monitor call center performance:

* **Monthly Call Trend** – Shows call volume trends across months.
* **Call Distribution by Day** – Displays number of calls handled on each day of the week.
* **Female vs Male Callers** – Compares caller distribution across different cities.
* **Customer Rating Analysis** – Shows rating distribution to evaluate service quality.
* **Representative Performance Filter** – Allows filtering performance by representatives (R01–R05).
* **City-Level Performance Table** – Shows revenue generated by representatives in Cincinnati, Cleveland, and Columbus.

## Insights

* October recorded the highest call volume in the year.
* Cleveland has the highest number of male callers.
* Customer ratings are mostly between **3 and 5**, indicating generally positive feedback.
* Representative performance varies across cities and revenue contributions.
